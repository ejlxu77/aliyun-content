## 个人版的计费到底怎么运转

个人版的计费分三层，理解了这三层，"按小时还是包月”的疑问就清楚了。

第一层是月度套餐。你在客户端里选购一款套餐（官方活动页当前展示黄金款、白金款、铂金款、钛金款、黑金款等款型），按月付费，套餐里每月发放一定数量的无影灵豆。这是预付费部分。

第二层是灵豆消耗。云电脑开机运行的时长决定扣多少灵豆。按官方产品页给出的换算关系，黄金款 40 颗灵豆对应 4核8G 开机 10 小时，白金款 160 颗对应 40 小时，钛金款 640 颗对应 160 小时——三组数据都指向同一个速率：**4核8G 机型每小时消耗约 4 颗灵豆，8核16G 机型每小时消耗约 8 颗**。关机后灵豆就不再走字。

第三层是补充购买。套餐灵豆用完了，云电脑不会直接停，你可以再买加时包续命；官方还有面向云游戏场景的畅玩游戏包等增值包可选。

真正支持“按小时后付费”的是同品牌的企业版：企业版可以按需购买，按云电脑实际运行小时出账。不过官方计费文档写得很明确——企业版与个人版（原标准版）是**完全独立的产品体系**，无影灵豆、套餐时长、优惠券等计费资源互不相通，不支持跨版本抵扣或转移。你没法买个人版套餐去抵企业版的按量账单，反过来也不行。
